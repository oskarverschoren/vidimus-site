VIDIMUS/VOOR AI-AGENTS

Laat uw agent het bewijs ophalen.

"Ga naar Vidimus en bezorg me het bewijs van dit betwiste geval." Vidimus is gebouwd om óók door agents gebruikt te worden — Claude, ChatGPT of uw eigen automatisering. Drie lagen: een leesbare samenvatting voor modellen (llms.txt), een volledig beschreven API (OpenAPI · Swagger) en een MCP-server met kant-en-klare tools. Publieke feiten zonder sleutel; uw eigen dossiers met de API-sleutel van uw organisatie.

01 · WAT EEN AGENT KAN DOEN

02 · MCP-SERVER (CLAUDE CODE, CLAUDE DESKTOP, ANDERE CLIENTS)

Voeg dit toe aan uw MCP-configuratie (bv. .mcp.json in uw project of ~/.claude.json). Zonder API-sleutel werken enkel de publieke tools.

{"mcpServers": {"vidimus": {
  "command": "python3", "args": ["-m", "vidimus.mcp_server"],
  "env": {"VIDIMUS_URL": "https://app.vidimus.be",
          "VIDIMUS_API_KEY": "vk_…uw organisatie-sleutel (Instellingen)…"}}}}

Tools: verify_registration · passport · verify_bundle_file · list_registrations · list_streams · get_dossier · get_content · download_bundle · lookup_file · register · create_share · tamper_check · usage · explain. Vereist Python 3.11+.

Gebruiker: "Bezorg me het bewijs van de betwiste aflevering van vrijdag, container MSKU 452 118-0."
Agent:  passport("MSKU 452 118-0")   → vindt de aflevering + de bevestiging van de terminal
        get_dossier(reg_…)           → het leesbare dossier
        download_bundle(reg_…)       → de cryptografische bewijsbundel (.zip)
        verify_bundle_file(zip)      → "zes controles: 6/6 — inhoud, handtekening,
                                        Merkle-pad, grootboek en tijdstempel kloppen."
03 · ZONDER VIDIMUS TE VERTROUWEN

Elke bewijsbundel bevat een zelfstandig controlescript (verify_bundle.py, alleen Python 3 nodig) en het RFC 3161-tijdstempeltoken van de onafhankelijke derde. Een agent — of uw IT — controleert dus zonder één verbinding met ons:

python3 verify_bundle.py bundel.zip     →  ok: 6/6
openssl ts -reply -token_in -in tijdstempel.tsr -text   →  tijdstip + Merkle-wortel van Sectigo
