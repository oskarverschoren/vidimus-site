Voor AI-agents · llms.txt · OpenAPI · MCP

Laat uw AI-agent het bewijs ophalen.
"Ga naar Vidimus en bezorg me het bewijs van dit betwiste geval."

Vidimus is gebouwd om ook door agents gebruikt te worden — Claude Code, Claude Desktop, ChatGPT-agents of uw eigen automatisering. Drie lagen: een leesbare samenvatting voor modellen (llms.txt), een volledig beschreven API (OpenAPI, Swagger) en een MCP-server met kant-en-klare tools. Publieke feiten zonder sleutel; uw eigen dossiers met de API-sleutel van uw organisatie.

Wat een agent kan doen

Opdracht van de gebruikerWat de agent doetSleutel
"Is registratie reg_… nog geldig en onaangeraakt?"GET /verify/{id} → zes controlesnee
"Toon me alles over zending VAC-2026-007."GET /passport/{ref} → alle partijen, tijdlijn (feiten)nee
"Controleer deze bewijsbundel die ik van een leverancier kreeg."POST /verify-upload (zip) → oordeel + controlesnee
"Bezorg me het bewijs van de meerwerkbon van blok B."GET /registrations?ref=… → /dossier → /bundleja
"Is dit pdf'je de versie die we destijds vastlegden?"SHA-256 lokaal → POST /lookup → match + bewijsja
"Leg deze afleverbon vast en laat de ontvanger tekenen."POST /ingest → POST /registrations/{id}/share (QR/mail)ja
"Wat kost ons dit bij 5.000 registraties?"GET /usage · POST /assistja

MCP-server (Claude Code, Claude Desktop, andere clients)

Voeg dit toe aan uw MCP-configuratie (bv. .mcp.json in uw project of ~/.claude.json). Zonder API-sleutel werken enkel de publieke tools.

{"mcpServers": {"vidimus": {
  "command": "python3", "args": ["-m", "vidimus.mcp_server"],
  "env": {"VIDIMUS_URL": "https://app.vidimus.be", "VIDIMUS_API_KEY": "vk_…uw organisatie-sleutel (Stromen)…"}}}}

Tools: verify_registration · passport · verify_bundle_file · list_registrations · list_streams · get_dossier · get_content · download_bundle · lookup_file · register · create_share · tamper_check · usage · explain. Installatie: pip install vidimus (binnenkort) of de map vidimus/ uit de broncode; vereist Python 3.11+.

Voorbeeld — zo verloopt het:

Gebruiker: "Ga naar Vidimus en bezorg me het bewijs van de betwiste aflevering van vrijdag, container MSKU 452 118-0."

Agent: passport("MSKU 452 118-0") → vindt de aflevering en de bevestiging van de terminal → get_dossier(reg_…) → download_bundle(reg_…) → verify_bundle_file(zip) → "Zes controles ✓. Verankerd 17/08 09:46 UTC met tijdstempel van Sectigo; de terminal bevestigde om 09:50 met een eigen sleutel: 'ontvangen zonder voorbehoud'. Bundel staat klaar in ./vidimus-bundle-reg_….zip; de tegenpartij kan ze zelf natellen met verify_bundle.py."

Rechtstreeks via de API

# publiek — geen sleutel
curl https://app.vidimus.be/verify/reg_66bfbe7909f2
curl https://app.vidimus.be/passport/VAC-2026-007

# uw organisatie — sleutel onder Stromen in de app
curl -H "x-api-key: vk_…" "https://app.vidimus.be/registrations?ref=VAC-2026-007"
curl -H "x-api-key: vk_…" https://app.vidimus.be/registrations/reg_…/dossier
curl -H "x-api-key: vk_…" -o bundel.zip https://app.vidimus.be/bundle/reg_…
curl -H "x-api-key: vk_…" -H "content-type: application/json" -d '{"sha256":"…64 hex…"}' https://app.vidimus.be/lookup
curl -H "x-api-key: vk_…" -H "content-type: application/json" -d '{"stream_id":"str_…","signer_id":"sgn_…","payload":{"bon":"MW-0047","bedrag":4380},"ref":"WERF-B"}' https://app.vidimus.be/ingest

Volledige beschrijving: openapi.json · interactief: app.vidimus.be/docs.

Spelregels voor agents

Publieke endpoints tonen alleen feiten (nooit inhoud). De API-sleutel is per organisatie en geeft enkel toegang tot háár data. Een agent mag nooit beweren dat iets "gekwalificeerd" is tenzij het dossier tier: qualified zegt, en geeft geen juridisch advies: Vidimus levert bewijsmateriaal, de rechter weegt (art. 8.11 BW). Verifiëren kan altijd zonder ons: python3 verify_bundle.py bundel.zip.
